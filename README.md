# Church Servants Manager (CSMS)

A comprehensive Flutter application designed to help church servants and administrators manage student data and church activities efficiently.

## App Purpose

The **Church Servants Manager** streamlines the process of tracking and managing student information within the church community. It provides a secure and user-friendly platform for servants to access student records, manage attendance, and coordinate service activities.

### Key Features

*   **Role-Based Access Control**: Specialized dashboards and permissions for **Admins** and **Servants**.
*   **Student Management**: Efficient tools to view, add, and update student profiles and data.
*   **Secure Authentication**: Powered by Firebase Auth, including email verification and role assignment.
*   **Modern Architecture**: Built with Flutter and the BLoC pattern for a responsive and scalable experience.
*   **Cloud Integration**: Utilizes Firebase Firestore for real-time data storage and management.
