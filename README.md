# CSMS - Church Servants Management System

A Flutter-based application designed to streamline the management of church services, servants, and students.

## Project Overview
CSMS provides a centralized platform for:
- **Role-Based Authentication**: Secure access for Admins, Servants, and Students using Firebase Auth.
- **Data Management**: Cloud-synced user profiles and roles via Firestore.
- **Attendance Tracking**: (In progress) Managing attendance for various church activities.
- **Real-time Updates**: Instant role refresh and profile management.

Built with Flutter and Firebase, following a clean architecture with Bloc for state management.
