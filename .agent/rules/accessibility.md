# Accessibility (A11Y)

Implement features to empower all users (varying abilities, ages, etc).

* **Color Contrast:** Text must have a contrast ratio of at least **4.5:1** against its background.
* **Dynamic Text Scaling:** UI must remain usable when system font size is increased.
* **Semantic Labels:** Use `Semantics` widget to provide clear labels.
* **Screen Readers:** Regularly test with TalkBack (Android) and VoiceOver (iOS).
